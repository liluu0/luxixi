The atlas and 15 gzip binary chunks are copied without geometry changes from Human Atlas. It contains 2,234 source meshes and 3,432 named FMA concepts. Human Atlas converted units and axes, simplified geometry, and quantized normals. This viewer adds Chinese landmark names, original interaction code, display colors, and rendering materials. Mesh counts do not represent counts of anatomical organs or bones.

Reference anatomy: BodyParts3D 4.0 adult male; educational visualization, not clinical measurements. No patient data or live biometric measurements are used.
