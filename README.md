# LUXIXI / 露西西个人网站

这是一个基于 Vue 3 + Vite 的个人作品集网站。页面以实验性、数据感和可玩性为主要视觉方向，用于展示个人介绍、创作方向、作品入口和联系方式。

## 本地运行

```powershell
npm install
.\node_modules\.bin\vite.cmd
```

启动后访问终端输出的本地地址，通常是 `http://localhost:5173/`。

生产构建：

```powershell
.\node_modules\.bin\vite.cmd build
```

## 页面结构

- `/`：个人首页，包含 Hero、关于我、精选作品和联系方式。
- `/works/city-heatmap`：城市脉冲实验室，展示省级地图、城市节点、指标切换、热力/流动图层、缩放拖拽和排名面板。
- `src/components/HomePage.vue`：首页内容和作品卡片。
- `src/components/ContactSection.vue`：联系方式、复制按钮和留言状态提示。
- `src/components/CityHeatmap.vue`：交互式城市数据可视化作品。
- `src/assets/china-provinces.json`：地图边界数据。
- `src/style.css`：全站视觉样式、响应式规则和动画。

## 当前交互

- 首页导航锚点滚动和作品详情路由切换。
- 联系方式复制到剪贴板。
- 留言表单目前只做前端预览，不会发送或保存数据。
- 城市实验室支持指标切换、省份和城市选择、地图缩放、拖拽、热力/流动图层切换。

## 后续建议

1. 为其他作品卡片补充真实详情页或项目链接，避免点击后停留在 `#`。
2. 如果需要接收留言，增加后端接口、校验、限流和隐私说明；当前表单文案已经明确不会保存内容。
3. 将城市实验室中的演示数据和“LIVE DATA”文案替换为真实数据接口，或明确标注为 Demo 数据。
4. 给首页补充项目缩略图、项目年份、职责和技术栈，方便访客快速理解作品价值。
5. 上线前补充 favicon、Open Graph 元信息、站点统计和 404 页面，并用 Lighthouse 检查移动端性能与可访问性。

## 注意事项

地图数据文件较大，构建时会被打包进前端资源。若未来数据继续增长，可以考虑按作品页懒加载，或改为压缩后的 GeoJSON。
