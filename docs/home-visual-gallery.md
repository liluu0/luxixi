# 首页视觉与四图轮播

更新日期：2026-09-16。

## 入口与页面顺序

首页锚点为 `/#visual-gallery`。本次开发预览地址为 http://127.0.0.1:5186/ ，后续端口以 Vite 启动日志为准。

页面顺序：首屏 → 01 关于我 → 02 脑内放映室 → 03 作品集 → 04 联系方式。

轮播位于 About 与 Works 之间，标题为“脑内放映室 / VISUAL EXPERIMENTS”，说明为“四帧想象，暂时逃离日常。”。

## 最终布局

- 桌面：图片带横贯视口，当前图片居中，存在相邻图片时在两侧露出；首图左侧、末图右侧留白，不复制图片补位。
- 单图保持原始 3:2 比例，不裁切主体；宽度为 `clamp(360px, 40vw, 640px)`，最高约 427px。
- 桌面图片间距为 `clamp(40px, 5vw, 100px)`，1920px 视口下约 96px。
- 标题与底部控制区保持正文宽度，最大 1180px。
- 700px 及以下：单图占满轮播容器，页面两侧各留 16px；图片间距 16px，控制区换行。
- 图片覆盖轻微深绿色蒙版，与首页暗色底和荧光绿细节呼应。

## 轮播行为

- 不自动播放，不循环：第一张不能继续向前，第四张不能继续向后，相应箭头禁用。
- 桌面支持拖拽、点击画面左/右半区切换；鼠标进入时显示圆形方向光标。
- 手机支持左右触摸滑动，保留纵向页面滚动和双指缩放，不显示圆形鼠标光标。
- 圆点可直接选择图片；轮播区聚焦后，左右方向键切换，Home / End 跳至首尾。
- 图片尚未加载时显示三个脉冲圆点，加载成功后淡入；失败时显示重试按钮。
- 轮播距视口约 400px 时开始加载四张图片；沿用首页 IntersectionObserver 的 `.reveal` / `.show`，滚动进入时渐入上移，只展现一次。
- 尊重减少动态效果设置，轮播取消动画并直接显示；图名通过礼貌播报区域更新。

## 标题与贴画交互

- 作品集：三个字错位排版，“品”使用荧光绿描边，“集”带紫色偏移阴影，底部为粉色手绘弧线；悬停轻微错动。
- 保持联系：奶白“保持”搭配淡紫色“联系”纸片，含半透明胶带细节；悬停或键盘聚焦时纸片翘起。点击标题可向小怪打招呼，取代原来的标题变色与状态轮换。
- 独眼小怪：悬停或键盘聚焦时跳跃摇摆并显示“HEY!”；点击（包括手机触摸）触发约 800ms 的打招呼状态。
- 联系方式复制与留言预览行为不变；打招呼仅是本地动效，不发送消息。
