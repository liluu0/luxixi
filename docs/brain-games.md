# 给大脑找点麻烦

入口：作品集第五张卡片，或 `/works/brain-games`。页面按需加载，使用 Vue、项目已有 Lucide 图标和新增 XState 5 状态机。

## 参考资料

于 2026-09-14 查阅以下公开页面，借鉴任务与交互设计，没有复制第三方代码或素材：

- [jsPsych 反应时实验教程](https://www.jspsych.org/v8/tutorials/rt-task/)：参考刺激呈现、作答记录和试次组织方式。本项目没有使用 jsPsych 实验框架，不将结果用于科研评估。
- [Stroop effect](https://en.wikipedia.org/wiki/Stroop_effect)：颜色名称与字色可能冲突，任务要求识别实际字色。
- [Human Benchmark 顺序记忆](https://humanbenchmark.com/tests/sequence)：相关同类项目。页面可访问，但 HTTP 读取仅返回客户端页面外壳，未据此声称验证其完整游戏规则。
- [XState](https://github.com/statelyai/xstate)：采用 npm 的 XState 5 管理准备、进行、结果和中断状态。

Chrome 插件因当前认证方式不兼容未能使用，资料通过 HTTP 读取，本地浏览器验证使用 Playwright CLI。

## 首版规则

| 挑战 | 正式模式 | 练习 | 输入 |
| --- | --- | --- | --- |
| 颜色别骗人 | 12 轮，每轮 5 秒，识别实际字色 | 3 轮 | 鼠标、触屏或数字键 1-4 |
| 记忆闪回 | 序列从 3 格递增到 10 格，逐格闪烁；输入限时 20 秒，错误即结束 | 3 格和 4 格 | 鼠标、触屏或数字键 1-9，按行排列 |
| 规则反转 | 12 轮，每轮 5 秒；同向选箭头方向，反向选相反方向 | 3 轮 | 鼠标、触屏或方向键 |

开始前选择输入方式，一局中固定方式，避免混合鼠标与键盘成绩。记忆允许重复格子，同一格连续出现时也有熄灭间隔。

颜色和反转记录正确题数、正确率、正确作答平均反应时；记忆记录最长完整复原序列。失败和超时不计入平均反应时。时钟使用 `performance.now()`，浏览器与输入设备仍会影响延迟，不提供人群百分位或智力判定。

## 状态与存储

- 切换标签页触发页面隐藏时中断本局，不保存中断成绩；需要重新开始。
- 返回列表和卸载页面取消所有计时器；答题后锁定输入，忽略按键自动重复。
- 练习不更新正式成绩。
- 本地最佳保存在 `localStorage` 的 `luxixi-brain-v1`，按游戏与输入方式区分。题数相同优先保留更短平均反应时。
- 存储不可用或 JSON 损坏时仍能游玩，并提示本地保存不可用。无账号、无后端上传。

## 验证

当前独立 worktree 的 Vite 构建通过。Playwright CLI 检查颜色练习与正式计分、键盘反转、逐格记忆播放与复原、记录写入、隐藏中断、首页入口与移动端溢出。

脚本和截图保存在 `output/playwright/`。自动化使用浏览器虚拟时钟加速测试，验证逻辑而非真实设备反应时。

开发服务器当前使用 `http://127.0.0.1:5180/`。生产托管需为 `/works/*` 配置 SPA 回退到 `index.html`。
